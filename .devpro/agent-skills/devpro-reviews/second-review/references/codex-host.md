# devpro:second-review — Codex host projection route

由 `SKILL.md` §Projection Routes 載入：當前 host 是 Codex 時讀，其他 host 不讀。本檔內「本 skill」指 `devpro:second-review`（`SKILL.md`）。

### Codex Host

Codex host MUST use projection-first routing when the runtime exposes `dp-second-reviewer`（`.codex/agents/dp-second-reviewer.toml` 或等價 runtime-native subagent）。TL 只交 bounded handoff inputs；final packet 與 `claude -p` invocation 屬 executor/adapter boundary，不是 TL default action。Codex host default reviewer route is `dp-second-reviewer` projection -> Claude-family reviewer；projection 內部 deterministic route chain 是：

1. `.devpro/agent-skills/devpro-reviews/second-review/SKILL.md`
2. `platform-adapters/codex.md`
3. `platform-adapters/codex-host-cross-review.md`
4. `.devpro/agent-skills-refs/autonomous-ai-agents/claude-code/SKILL.md`
5. `platform-adapters/claude-code-cross-review.md`
6. executor-internal direct `claude -p` packet mode with Claude sticky self-write-back（terminal argv MUST pin `--model <resolved>` + probe-backed highest-compatible `--effort` within handoff `reviewer_effort_ceiling`（default `xhigh`；`max` only when ceiling `max` and functional probe compatible；`max` incompatible keep `xhigh`；`xhigh` incompatible fail closed）；禁 fixed effort=`high`／omit-model）。`.codex/agents/dp-second-reviewer.toml` `model_reasoning_effort=xhigh` is wrapper/Codex projection layer, NOT terminal `claude -p --effort`。`<resolved>` 為探測後釘選的 exact model，可經 `DEVPRO_SECOND_REVIEWER_MODEL_CLAUDE` 覆寫；政策 selector 集中宣告於 `second-reviewer-cli-recipe-contract.mjs` 的 `SECOND_REVIEWER_MODEL_DEFAULTS`；實際 exact model 與探測證據以 renderer 的 `reviewer_model_selection` 為準。

Projection observability: if the unmarked outer wrapper invokes `claude -p` or another reviewer CLI internally, it MUST use TL-supplied renderer-generated `packet_path`, `observability_context_path`, `heartbeat_path`, `activity_log_path`, `stdout_log_path`, `stderr_log_path`, `cli_probe_result_path`, `projection_bootstrap_command`, and `projection_runner_command`. Missing paths are `projection_observability_contract_missing` before reviewer CLI. The sidecar requires `reviewer_surface: host-non-sandbox-required`；without a host/non-sandbox runner, return `projection_runner_unavailable` before dispatch.

The wrapper first executable action executes exact `projection_runner_command`；the marked terminal reviewer receives only packet stdin. The runner is the sole caller of bootstrap/acknowledgement；TL and projection instructions MUST NOT pre-call either command. The runner first sanitizes its own dispatch env（bounded cmux PATH entries removed; NODE_OPTIONS cleared on cmux evidence）then performs the same bounded first-PATH-hit realpath gate after acknowledgement plus dispatch identity-collision validation and before sticky/scope/help/auth/reviewer work；exact `tool_discovery_blocked` is a no-claim `spawn_or_probe_failure`. On Win32 it follows native path/delimiter plus valid PATHEXT order, ignores extensionless and malformed tokens, direct-trusts only `.COM`/`.EXE`, and blocks the first existing shell-dependent candidate without fallback or shell interpretation. One trusted absolute realpath is bound across help/auth/reviewer spawns without argv rewrite or second PATH resolution；path-bearing probe failures restore the logical tool and expose only stable generic/code evidence. Runner preserves sidecar event order and emits exactly one `projection_handoff_validated` on success；at hard cap verification precedes timeout/termination。Post-PR exact current-head marker-matching `PASS`保留consumer gate success且later `cli_exit.timed_out`仍可觀測、不要求receipts；`WARN`須無current fault與完整receipt chain。Actual merge hook Path F驗exactly-one canonical current-head `PASS|WARN`，並拒絕known operator-disposed dispatch；正常PASS不新增local receipt要求。Extra/missing/reordered entries fail closed；stale sticky不算 write attempt。

TL waits the runtime completion callback/event and MUST NOT use periodic polling or list-agents busy wait when callback-capable. Only when no callback/event exists and active monitoring is required may TL use bounded `60s` artifact/sticky polls，at most 30 attempts and total hard cap `30m`. The no-callback first 60s observation window MUST see terminal status、fresh sticky、or post-handoff heartbeat/activity；otherwise classify `projection_activity_stale` without waiting `30m`. `projection_log_unavailable_by_runtime_api` does not waive renderer-generated wrapper-owned artifacts；missing/stale artifacts remain `projection_observability_contract_missing` / `projection_activity_stale`. The reviewer packet MUST NOT ask the reviewer to create those artifacts with Python/heredoc/pipes/redirection/loops.

TL MAY use the direct `claude -p` adapter recipe only as `projection_unavailable` / `projection_runner_unavailable` / `tool_discovery_blocked` / explicit manual fallback / explicit projection failure / stale-or-no-fresh-sticky-after-projection-observation-window, and MUST record that fallback reason in the handoff or final report. Codex projection 不得把 Codex reviewer 當 default reviewer。若 Claude-family reviewer 不可用、未授權，或使用者明示選擇 fallback，才可用 Codex-family `same-family fallback`，且必須寫 `reason:` / provenance；strict cross-model 時寫 `UNAVAILABLE` 或 human handoff。
